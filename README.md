# 自动化数据分析报告生成工具

**A Lightweight CSV Data Analyzer**

自动化数据分析报告生成工具 是一个基于 Python 开发的轻量级 CSV 数据自动分析工具，旨在帮助用户快速了解陌生数据集，简化初步数据探索流程，将更多精力投入后续的数据处理与建模。

拖入一份 CSV，工具会自动完成「读数据 → 认变量 → 算统计 → 查质量 → 挖时间规律 → 算相关性 → 出图 → 生成报告」的完整链路，最终产出**一份静态分析报告**和**一份可交互的 HTML 看板**。

本项目主要用于学习、研究和数据探索，欢迎交流与改进。

## 功能介绍

### 1. 数据读取与预处理

- 自动尝试 `UTF-8 / UTF-8-SIG / GB18030 / GBK` 四种编码，中文 CSV 不再乱码。
- 自动清理无名列、空列与重复列名。
- 自动完成：数值列的缺失标记（如 `-`、`NA`）转换、日期列与时间列解析、**日期 + 时间自动合并为完整时间戳**。

### 2. 变量类型自动识别（9 类）

`数值 / 分类 / 低基数数值分类 / 二元 / 布尔 / 日期时间 / 时间索引 / 长文本 / 标识符`

- 结合**列名关键词**与**取值特征**双重判断（例如「用户 ID」「UID」自动判为标识符）。
- 分析前可打开确认对话框，**逐列人工指定**为数值变量、分类变量、标识符或时间变量，覆盖自动判断结果。
- 高基数标识符不会污染分类变量下拉框。

### 3. 描述性统计

- **数值变量**：样本量、缺失数、均值、中位数、标准差、方差、最小/最大值、极差、9 个分位数（1/5/10/25/50/75/90/95/99）、四分位距 IQR、偏度、峰度、绝对中位差 MAD、变异系数、异常值统计、正态性检验。
- **分类变量**：取值个数、众数及其占比、信息熵、归一化熵、完整频数表（含占比）。

### 4. 数据质量检查

缺失值、重复记录、常数变量、高基数变量、异常值（IQR 法）、偏度异常、类型不一致——逐项给出结论。

### 5. 缺失值模式分析

总体缺失情况、逐变量缺失情况、最常见的缺失组合模式 Top N、变量两两共同缺失情况。用于判断缺失是「随机」还是「成片出现」。

### 6. 时间分析

- 时间范围与采样间隔分布，小时 / 星期 / 日期维度分布。
- 自动识别采样频率（日 / 周 / 月 …）并按频率重采样聚合。
- 时间序列：线性趋势拟合 + 异常点检测。

### 7. 相关性分析

- 同时计算 **Pearson / Spearman / Kendall** 三套相关矩阵，附相关系数热力图。
- 自动提取强相关变量对，按相关强度分级。

### 8. 统计图表

直方图、箱线图、分类条形图、散点图、相关性热力图、时间分布图（小时/星期/日期）、时间序列趋势图。图片以 base64 内嵌，报告可单文件分享。

## 产出两份报告

分析完成后在输出目录生成两个文件（默认标题为「文件名 + 报告」，便于多份报告同时打开时区分）：

| 文件 | 说明 |
| --- | --- |
| `report.html` | **静态分析报告**：数据集概况 → 变量概况 → 描述性统计 → 数据质量检查 → 缺失值模式分析 → 时间分析 → 相关性分析 → 数据可视化，共六章，可直接打印或归档。 |
| `dashboard.html` | **交互式看板**：单文件、数据内嵌、无需后端，双击即可在浏览器里继续探索。 |

### 交互式看板能做什么

**查询与筛选**

- **标识符查询**：按单个标识符（支持部分匹配）或多达 4 个字段的**标识符组合**查询，结果联动下方全部图表。适合「看某一个用户 / 某一只股票」的个体视角。
- **变量条件筛选**：数值变量按区间筛选，分类变量按取值多选筛选。
- **时间范围筛选**：填写起始 / 结束时间后应用（仅在数据含时间变量时出现）。

**八张可交互图表**

数值分布、变量关系（散点）、时间变化、归一化变量关系、归一化时间变化、分类变量频数分布、数值变量按类别统计、分类变量占比饼图。

- **数据变量可多选**：一次勾选多个数值变量，同一张图里并排对比。
- **按分类变量分组**：分组后每个类别一条曲线/一组柱子。
- **时间聚合方式可选**：同一时间存在多条记录时，可选「时间桶聚合（取均值）」或「直接相加（求和）」，并会提示当前是否基于抽样样本。
- **分类变量占比饼图**：百分比 / 频数两种展示，类别过多时自动合并为「其他」。
- **数值变量按类别统计**：可选均值或合计，支持多变量对比。
- **图例可点击**：单击图例隐藏/恢复对应数据；已分组时可一次性隐藏某个分组的全部数据；另提供「隐藏全部 / 显示全部 / 反选」工具条和每张图的一键隐藏按钮。

**自适应与裁剪**

- 按数据集实际字段**自动隐藏无数据的板块**（没有时间变量就不渲染时间图，没有分类变量就不渲染分类图，数值变量少于 2 个就不渲染关系图）。
- 分类取值过多时自动压缩图例样式并撑高容器，避免图例显示不全。

## 桌面程序（GUI）

- 拖拽 CSV 到窗口，或点击按钮选择文件。
- 可自定义**报告导出目录**（默认项目下 `output/`）。
- 分析前弹出**变量类型确认表**，逐列核对/修正自动识别结果。
- 实时进度条与状态提示，分析在后台线程执行，界面不卡死。
- 完成后状态栏显示两份报告的**实际占用大小**，并可直接一键打开任一份报告。

## 体积与性能控制

- 交互式报告默认对行级数据**抽样**（上限 5,000 行）以保证打开速度和文件体积；勾选「导出全部数据」则写入全量原始行。
- 时间序列、标识符等模块各有独立的采样上限；静态图散点最多 10,000 点，交互式看板 5,000 点。
- 界面不再预估体积，改为**生成完成后直接显示真实大小**。

## 风险与注意事项

* **分析结果仅供参考**：自动识别的变量类型和统计结果可能存在误差，建议结合数据背景进行核验。
* **不替代专业分析**：工具主要用于初步探索，不能替代严谨的数据清洗、统计推断和建模过程。
* **注意数据隐私**：请勿在不可信的环境中处理包含个人隐私或敏感信息的数据。
* **注意数据规模**：较大的 CSV 文件可能占用较多内存，影响运行速度。
* **可执行文件需放在可写目录**：报告输出到 exe 同级 `output` 目录，建议不要放在 `Program Files` 等只读位置或 OneDrive 等同步目录。

## 使用教程

### 1. 环境要求

建议使用 Python 3.10 或更高版本。

### 2. 下载项目

```bash
git clone https://github.com/xiaolaoba618/csv-analyzer.git
cd csv-analyzer
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

如果项目尚未提供 `requirements.txt`，请根据实际使用的 Python 库安装依赖。

### 4. 启动程序

在项目根目录运行：

```bash
python ./gui/app.py
```

现已推出release版，可直接下载可执行文件exe。

如果项目入口文件名称不同，请替换为实际的 GUI 启动文件。

### 5. 分析数据

1. 启动程序并选择需要分析的 CSV 文件。
2. 根据需要调整变量类型和分析选项。
3. 执行分析并查看统计结果。
4. 在指定的导出目录中查看生成的 HTML 报告和 Dashboard。

## 依赖要求

项目基于 Python 开发，主要依赖包括：

* Python
* PySide6：图形界面
* pandas：数据读取与处理
* NumPy：数值计算
* Matplotlib：统计图表
* Scipy：统计方法

具体依赖版本请以项目的 `requirements.txt` 为准。
